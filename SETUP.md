# Setup

1. Download and extract this package.
2. Open `README.md` and review every project description and contribution statement.
3. Upload the contents of this folder to the repository named `VedantDG-07` (your GitHub profile README repository).
4. Ensure `assets/hero.svg` and `.github/workflows/snake.yml` are included.
5. In the GitHub repository, open **Settings → Actions → General** and allow the workflow to create and approve pull requests / write repository contents if required by your repository settings.
6. Open **Actions**, run **Generate contribution snake** once using **Run workflow**. The workflow publishes generated images to the `output` branch.

Notes:
- The snake graphic may not appear until the workflow has run successfully and the `output` branch exists.
- GitHub README images and external stats services depend on third-party availability.
- Review project features and technologies against your current repositories before publishing. Keep contribution descriptions honest.
